# Tiny live feasibility source plan v1

The user accepted model adapters and a small recorded trial. This freezes inputs,
source expectations, ordering and finite ceilings for **backend/D/E/search
feasibility**. It does not replace the future D/E/I/R/B comparison. The actual
runner, prompts, schemas, executable and isolation review must be pinned in
immutable execution capsules before their respective stages. An incomplete
capsule blocks dispatch. Use preflight **v2**; v1 records the discovered retry
configuration mistake and remains preserved.

The fixed-source pair uses only P01/P02 of the existing synthetic mixed fixture:
three unique versions, four observations, bridge/museum/transit facts, a thin
stub and an exact repeat. Same raw fields and cutoffs underlie D and E; no source
truncation or case-grouping hints are introduced. E makes three source-local
extractions at P01 and reuses V001 for R004 at P02. Reconstructions have no prior
view; only each separately budgeted comparator sees its arm's prior publication.
Source-only expectations were written before outputs, from already familiar
synthetic controls. They are not new prefix-blind gold or a holdout.

| Stage | Exact application invocation schedule | Maximum |
| --- | --- | ---: |
| Transport | Initial ack; conditional diagnostic only after eligible known-usage failure | 2 |
| Fixed P01 | D, delta D; E extract V001/V002/V003; E, delta E | 7 |
| Fixed P02 | E, delta E; D, delta D | 4 |
| Search | One query planner; after recorded evidence and source-only freeze: D off, delta off; D on, delta on | 5 |
| Total | One trial; no reallocation of unused probe/recovery slots | 18 |

The machine manifest fixes every call ID and deadline. Fixed D costs four calls;
E costs seven including all three extraction calls. Actual fixed D/E cost is
11, with extraction counted once. Repeated-source reuse is not free new
extraction, and future I/R/B work receives no budget here. Source-bearing calls
use Astra/medium and require reviewed preventive isolation from hosted search,
files, tools, plugins and child agents.

Every invocation reserves 24,000 input / 4,000 output tokens, totaling 432,000 /
72,000 scheduled reservations if both probes execute. The overall stop thresholds
are 480,000 / 72,000. These are **not hard token caps**: no backend-enforced output
bound/input admission proof exists, one-call overshoot can occur, and unknown
application usage stops all later dispatch. Controller/process retries are zero;
built-in HTTP/SSE/auth retries are unknown. The invocation ceiling is not a
hidden upstream request or financial ceiling.

Per-call deadlines are at most 120 seconds; their maximum sum is 1,650 seconds.
The shared total is 1,800 model-active seconds and 2,700 elapsed live seconds,
starting with the first preflight dispatch. Stage ceilings, two total application
failures and one failure per arm also apply. At each step use the stricter
remaining budget, including cancellation/cleanup and unsuccessful attempts.
Creating new directories does not reset clocks or usage. Failed dependencies
remain failed/pending; no automatic retry, stale-output substitution or manual
patch is allowed.

Search uses the first neutral source M001 from the already-frozen observed
export, chosen by deterministic order before its text was read. It is a Guardian
headline about India's Cockroach movement/voter-roll protests with only a photo
credit as body text. The original capture is October 5; the frozen prospective
trigger is November 1 at 12:14:57 UTC. Search and fetched versions get their real
current request/result timestamps. This cannot reconstruct historical search or
prove that nothing happened in the missing interval. Real source text remains
under ignored `.news/`; tracked source and selection hashes preserve provenance.

One Astra/medium planner, with tools disabled, may propose at most two targeted
queries. Root/controller makes at most two single-query search attempts and three
single-URL fetch attempts through `runtime-web-run-single-operation`, recording
requests before dispatch. Fetch the insufficient-body seed URL first, then up to
two unique HTTP(S) URLs in recorded query/rank order; remove fragments only, with
no model/manual reranking or replacement. No search preflight consumes extra
tools. The provider's internal requests/retries/mode/tokens/cost remain unknown.
The cap describes controller-visible operations. Exact returned text is retained
with snapshots/hashes and full/excerpt/unknown status; snippets are only leads.
Unsupported capture preserves the failure and blocks the search pair, while
eligible fixed-source work can continue.

Before **either** search-condition output, a separate source-only reviewer must
freeze newly admitted text expectations, ambiguity and the common final observed
cutoff. If this cannot fit the remaining live/research budget, the pair stays
pending. Evaluate correctness against each condition's available required facts;
report expanded-only units as unavailable in off, not inference failures. Report
additional supported findings against the frozen expanded union separately.
That search-derived union is incomplete. Both pair comparisons start from null
publication, so their deltas exercise the interface and cannot establish useful
current-day novelty. Older publication must not become a current occurrence.

Research preparation, implementation, source review, one independent review and
one correction/recheck cycle share six aggregate active agent-hours and one
elapsed working day. Research tokens/cost are unknown; no global financial cap
is claimed. No external application semantic judge calls are allocated. A
separate reviewer can describe source-grounded failures and disagreements within
that work budget; this screen estimates no semantic quality rate. Full mixed
source slices, human importance/usefulness, automatic repair, natural 30–90-day
continuity, holdout performance and architecture selection remain unmeasured.
